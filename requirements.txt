# Python dependencies for the backend and the Vercel function. The modelling
# stack is pinned exactly: joblib artefacts are pickles, and scikit-learn does
# not support loading them under a different version. artefacts.load() refuses
# to start if the installed scikit-learn differs from the sklearn_version an
# artefact records.
#
# This is the single source of the pinned stack. It lives at the repository
# root because Vercel reads requirements.txt only from there and does not
# follow -r includes (AGENTS.md section 0.3); backend/requirements.txt points
# here.
#
# The artefacts were built on numpy 2.4.0 (README "Built against"), which has
# since been yanked on PyPI. 2.4.6 is pinned instead: it was verified
# bit-identical to 2.4.0 on every live prediction (661 value players, 315
# style players) and every served forecast (2,967 matches). scipy and joblib
# are pinned to the versions that verification ran on, so a fresh install
# cannot drift from them.
fastapi>=0.115
uvicorn[standard]>=0.30
pandas==2.3.3
numpy==2.4.6
scipy==1.17.0
joblib==1.5.3
scikit-learn==1.9.0
